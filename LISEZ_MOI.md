# Site vitrine Stud'Éval (stud-eval.fr)

Copie de travail du site, récupérée depuis le site en ligne le 6 novembre 2026.
Les 9 pages HTML contiennent leurs images. Le site est hébergé chez OVH.

- **Aperçu** : ouvrir une page `.html` dans Chrome.
- **Publication** : envoyer les fichiers modifiés chez OVH par FTP (fait par une personne, pas par l'assistant).
- Chaque modification est enregistrée dans Git : on peut voir l'historique et revenir en arrière.
